# SpaceXAI — 2026-10-20

Since 2026-10-19. Official SpaceXAI updates (SpaceXAI was xAI). The desktop Grok Bot changelog moved. The normal Grok Build update did not.

- **October 19 — Grok Bot 0.71.2 is on the public changelog.** The page dates the build October 14 and also covers 0.71.0 and 0.71.1. Yesterday the public page still stopped at 0.70.2. Eric at SpaceXAI posted that it is out. A form the Bot asks you to fill in can arrive with the known fields already filled, and you can edit them before you submit. You can attach files up to 250 MB and videos up to 1 GB, and one message can carry 20 files instead of 6. A voice call from your phone wakes the Bot's sleeping computer, so it can work with what you said after the call. The app opens while that computer is still starting, instead of waiting on a full-screen setup. Plugins can supply up to 200 skills instead of 24. If the computer runs low on disk, the Bot tells you once and deletes files only if you agree. On Windows, pasting a list into the message box stays on one line, and text you copy out of a chat keeps accents and curly quotes. The notes also repeat the plus-address email and "notify the computer you are using" items already on file. [Grok Bot changelog](https://x.ai/changelog/bot#v0.71.2) · [eric zakariasson, SpaceXAI](https://x.com/ericzakariasson/status/2112299456255381600)
  for Jaron: Update Grok Bot on the MSI when it offers 0.71.2. You can hand it bigger files, forms show up already filled in, and a voice call from your phone wakes the Bot's computer so it can keep working.

- **October 19 — Grok Bot can be the iPhone Action Button.** On an iPhone 15 Pro or later, update Grok Bot to 1.16, then go to Settings → Action Button, swipe to Shortcut, and choose Grok Bot → Start Voice Chat. One press starts a voice chat. The App Store listing is still 1.16.0 and still only names the gray plus-button fix. [Grok Bot](https://x.com/bot/status/2112252507762368684) · [setup](https://x.com/bot/status/2112282506284445787) · [eric zakariasson, SpaceXAI](https://x.com/ericzakariasson/status/2112299468335059287)
  for Jaron: If your iPhone has an Action Button, set it to start a Grok Bot voice chat. The 1.16 update from yesterday is the one this uses.

- **October 19 — Grok Build's early channel is 1.0.64.** The normal update is still 1.0.62. In the early build, a new session that fails to start puts what you typed back in the box. Voice dictation grows the box as you speak. Auto mode asks before a shell command unless every part of it is on the allow list. Hooks in a folder you have not trusted wait until you trust it.
