# OpenAI — 2026-10-09

Since 2026-10-08. Official OpenAI product updates:

- **October 8 — Faster steering is rolling out in Codex for the ChatGPT desktop app.** When you send a follow-up to correct or redirect a running task, Codex can respond to that change sooner. You can set whether follow-ups steer the current run or queue for the next one in Settings → General → Follow-up behavior. Availability varies during rollout.
