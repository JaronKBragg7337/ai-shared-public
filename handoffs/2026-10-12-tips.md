## To switch payments on later (after LLC EIN + business bank)
1. Create the Stripe account on the LLC. Create a Payment Link "Tip" with customer-chosen amount.
2. Paste the https://buy.stripe.com/... URL into TIP_LINK in tv/tips.js (marked PLUG-IN SPOT). The page appends ?client_reference_id=<tv_items.id>.
3. Build the webhook (Supabase Edge Function, service role): on checkout.session.completed insert into video_tips (item_id = client_reference_id, amount_cents = amount_total, provider_ref = session id, status 'paid'); verify the Stripe signature. provider_ref is unique so replays do not double count. Handle refunds by setting status 'refunded'.
4. Test with Stripe test mode: a test payment should raise that video's total in video_tip_totals.
5. Set tips_enabled = 1 in the Control Room (/admin/control/). The button needs BOTH the switch = 1 and a non-empty TIP_LINK.
