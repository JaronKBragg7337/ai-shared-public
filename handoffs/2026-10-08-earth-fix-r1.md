# Earth start fix round 1 - 2026-10-08

Commit d153305 on main (build 714b42a01a8aa6cad4f1). Live: https://www.heartbeatobservatory.com/games/the-cosmos/
Playtester report that found these: state/playtest/2026-10-08_15-18/REPORT.md. Re-run on the fix: state/playtest/2026-10-08_16-47/REPORT.md (0 blockers, 0 serious).

## Finding -> cause -> fix
1. BLOCKER x70 desktop / x5 iPhone, "Cannot read 'id' of undefined" in MultiplayerView.shipPose, iPhone went black.
   Cause: not Earth, and not the refresh itself. The live world has crew hired onto a ship whose owner is parked (Visitor 701; Jorge, Zuri Okafor 1, Ada Chen 1). The server strips parked ships from what it sends but left their crew in the pool. Once any player's opening ended, updateBodies asked for the pose of that missing ship every frame and threw, so the frame loop died. (Opening players do not draw people, which is why it only began at "opening finished".) Any new player on the live world could hit this, any start world.
   Fix: server publicState drops pool crew whose ship is not sent (authority.mjs); the view skips them too (multiplayerView.js updateBodies) so an old server cannot crash it.
2. BLOCKER (third): "null is not an object (evaluating view.ship)" in RemoteCrew, main.js, after the reload at the end of the tour; boot stuck on "Loading the port..." for 120 s.
   Cause: a race. The port people finished building before the shared view (multiplayer) was created further down main.js, so RemoteCrew got null. Fast on a reload with cached files.
   Fix: build starts where it did; RemoteCrew and CrewUI are attached after the shared view exists (main.js).
3. "Nothing changed for 60+ seconds" x16 and "Could not walk to ..." x7: bot steering. The bot walks to the Mars port people (distance 1e9 m); the Earth start has none of them (Okafor and Pruitt are the only people). Position was at Earth's radius but the frame said "Back in Mars space." - a knock-on of the crashed frame loop in 1; it did not recur. Not fixed in the game; the playtester's tour list needs an Earth list (open).
4. "Cockpit view on Mars (Valles Marineris)" in an Earth-opening desktop frame: same knock-on (frame set to Mars while the loop was dead, dark frame). In the re-run every post-opening frame is the Skyward Launch Complex under blue sky ("Earth frame." toast); no Mars frame found.
