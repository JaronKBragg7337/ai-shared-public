# The depth standard (Jaron 11/15/2026 10:45 AM: "that's how deep I want things to go... every time any build happens")

The example he pointed to: the "What Heartbeat Is - sources" agent brief (11/15 10:43 AM). Why it hit:
1. Gather BEFORE writing: every source named (transcript search terms, timeline, plans, principles, handoffs, LLC papers, site copy, old ChatGPT talks).
2. His words first, dated and sourced; AI summaries marked as AI.
3. Show where things CONFLICT or changed over time, old vs new, with dates.
4. List the GAPS (questions nothing answers yet).
5. Clear output file + short report; privacy lines stated.
6. Several of these run at the same time on different angles (research, design, blind second opinion, backtest).

Apply to every build (game, app, page, system): before building, one agent gathers everything already said/built about it (+ conflicts + gaps); in parallel, a blind second design; then build; then test/backtest against reality.
