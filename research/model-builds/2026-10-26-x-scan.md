# What people built with each model (Grok Build X scan + Claude web scan, 2026-10-26 ~12:55 AM)
For the engine bake-off (Fable 5.1 / OpenAI one / Kimi K3.1 Pro / Sonnet 5.5, same brief each). Claims are posts, not verified.
- **Astra:** best at one-shot playable 3D games + shader cinematics (@theo, @birdabo 45 min Blender MCP + concept images, @superalesha 25 min). Expensive: Plus 5-h window dies in ~3 tasks; a jungle shrine cost Astra 13% of a week vs Sol 4% (@maxt3chno). 3DVerifierBench 66% vs humans 88%.
- **Sol 6.1:** Blender/3D assets, ~3x cheaper on quota, finer detail (shrine: 49 min / 4%, preferred over Astra); 16 h autonomous Blender+Three.js (@TokenGremlin). Slower; can hit limits mid-project.
- **Fable 5.1:** Blender jet engine 84 parts, voxel pipeline with Hunyuan + headless Blender rigging; real engine with Opus 5.5 but review found duplicate systems/leaks. Price complaints are API-dollar (we're on Max, own limit).
- **Kimi K3.1 Pro:** cheap 3D objects/scenes; several "Kimi 3D" demos are really Tripo meshes. Quotas burned fast at launch.
- **Sonnet 5.5:** overnight engine fixing, self-tests (@Vectorxeth ocean 72 min, 12 self-tests); less wow, the reliable mule.
- **Shared tricks:** concept images first, compare in-game screenshots to the target and fix; one reference + Blender MCP look-compare-fix; four views -> 3D mesh -> rig; one job per session overnight.
