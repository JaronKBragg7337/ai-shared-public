The usual answer is **astatine** (element 85).

It’s a naturally occurring radioactive element, but it has no stable isotope—its longest-lived isotope has a half-life of only about **8 hours**. Because of that, any astatine produced by radioactive decay disappears quickly, so only minuscule trace amounts exist at any time.

Strictly speaking, “rarest” depends on definition: if you count human-made elements, something like **oganesson** (element 118) has been produced only a few atoms at a time, so it is even rarer—but it isn’t a natural material.
