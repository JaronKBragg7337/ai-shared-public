**s4 — Wrong/imprecise:** “The second explanation is to change gravity. … Below a very small acceleration, gravity would be stronger than Newton’s law says.”

MOND modifies Newtonian dynamics. Its effects can be formulated as modified gravity or modified inertia, so saying MOND necessarily changes gravity is too broad. The low-acceleration description is a useful shorthand for the effective acceleration, but it does not apply to every formulation in the same way. [Milgrom’s review of MOND formulations](https://ned.ipac.caltech.edu/level5/March01/Milgrom/Milgrom1.html), [MNRAS review](https://academic.oup.com/mnras/article/437/3/2531/1028289).

**Correction:** “The second explanation is to modify Newtonian dynamics. In gravity-based versions, below a very small acceleration, the effective gravitational acceleration can exceed Newton’s prediction.”
