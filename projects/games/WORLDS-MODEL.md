# How the worlds work (Jaron, 11/5/2026 10:16 AM). Read this before building or describing any world.

**One account, many environments.** Every world is a different *environment* for the same set of experiences.
Same phone, same account and same friends in every world. Switching worlds is like transforming into a new place
in the metaverse while staying together.

**Shared building types live in EVERY world**, each in that world's own style:
- a theater (watch a movie together; in VR later),
- an arcade or game building (opens the games),
- buildings and objects that open site pages (library, social, news, Wikipedia-style pages...).
A building is never "moved" from one world to another. Each world gets its OWN version. The Grand Palace is Ashgrove's
theater (world3/cinema.js) AND World 2 has its own Grand Palace. A futuristic world would have a sci-fi theater; same
experience, different look.

**The rule from the first world (Town Square):** walk up to a building and either it IS a site page (go inside = open it),
or inside it are objects you interact with to go somewhere (a game, a website, a social page). Anything someone would want
to do digitally has a way to do it in a world. The regular website stays the non-immersive way to do the same things.

**Each world also has its own plans** on top of the shared ones (e.g. NPCs that do jobs, which players can take over
and earn from; responsibilities, not just running around). Underlying principles repeat; details differ. Some plans are
paused while Jaron is still creating. Paused != dropped.

**World rings** (11/5): the home page shows 3 worlds at a time with a button that rolls which 3. Current 3 = Heartbeat
Classics (Town Square, World 2, Ashgrove). Other rings: Realistic (real-mapped cities), Futuristic (flying cars, robot
delivery), Space, past eras... Only real worlds of this class go in rings. Site pages, labs and games are NOT worlds;
they live INSIDE worlds as buildings and objects (see memory: worlds-are-not-pages).

Built for VR later. Phones first now. Players WALK (invisible floating thumbstick), never tap-to-walk.

## Buildings can be claimed (Jaron, 11/5 10:21 AM)
- Every building can be interacted with. Some are businesses.
- A building can be **claimed by a human or an AI**; going inside a claimed building is the claimer's space.
- A business can be **bought out** by another human or AI. Ownership falls back to open after **inactivity**, so the world
  keeps growing and turning over as new people join.
